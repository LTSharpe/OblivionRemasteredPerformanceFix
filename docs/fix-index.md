# Fix index

One row per fix: the ini key (its stable name), the log tag its lines carry, the source file, and what it changes.
Meant to be searched, not read whole: grep this file for an ini key, a log tag (`[bone]`) or a source file
(`render/bone_upload.cpp`) and read only that row. Moved out of [AGENTS.md](../AGENTS.md) so agents that load
AGENTS.md at every session start do not pay for the 100+ rows. A new fix adds its row here.

Columns: **Area** = the source folder group; **ini key** = the switch in `[Fixes]` (`[General]` for log keys);
**log tag** = the prefix of the fix's lines in `OblivionPerfFix.log`; **source** = file under `src/OblivionPerfFix/src/`;
**what it changes** = one line.

The ini key is a fix's stable name (docs and source comments use it). Evidence per fix in [research.md](research.md), plain
words in [how-it-works.md](how-it-works.md), both in this order. The shipped ini has three parts: performance improvements (all
on), game bug fixes (on, except `AutosaveFollowsMenu` and `FullscreenAllResolutions`; marked "game bug fix" or "game bug"
below, the crash guards with them) and optional tweaks (marked "off, optional tweak" or "off, trade-off": they may change
the look or how the game plays), then the diagnostics (off). Every key is read from `[Fixes]` (`[General]` for the log
keys): the parts are comment headings only, so an older ini still works.
